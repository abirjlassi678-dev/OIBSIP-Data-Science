# OIBSIP Data Science Internship

This repository contains the projects completed as part of the **OASIS INFOBYTE (OIBSIP) Data Science Internship**. The projects demonstrate practical skills in Python, data analysis, data visualization, and machine learning.

## Task 1: Iris Flower Classification

### Project Overview
The objective is to build a Machine Learning model that classifies Iris flowers into three species: Setosa, Versicolor, and Virginica.

### Dataset
The Iris dataset contains 150 observations and 4 numerical features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Random Forest Classifier

### Project Workflow
1. Loaded and explored the dataset.
2. Checked for missing values.
3. Split the data into training and testing sets.
4. Trained a Random Forest classification model.
5. Evaluated model performance using classification metrics.
6. Visualized flower measurements.

### Results
- Total observations: 150
- Test samples: 30
- Model accuracy: 90%
- Missing values: 0

**Conclusion:** The Random Forest model achieved 90% accuracy on the test dataset.

## Task 2: Unemployment Analysis

### Project Overview
This project analyzes unemployment data to explore unemployment trends and differences across regions during 2020.

### Technologies Used
- Python
- Pandas
- Matplotlib
- Data Cleaning
- Exploratory Data Analysis (EDA)

### Project Workflow
1. Loaded the unemployment dataset.
2. Cleaned column names and converted dates to datetime format.
3. Examined the dataset for missing values.
4. Analyzed unemployment statistics.
5. Compared unemployment rates across regions.

### Key Findings
- The dataset covers January to October 2020.
- The average unemployment rate in the dataset is approximately 12.24%.
- The analysis highlights differences in unemployment rates across regions.

**Conclusion:** This project demonstrates how Python can be used to clean, explore, and analyze unemployment data.

## Task 3: Sales Data Analysis

### Project Overview
This project explores supermarket sales data to understand sales performance, product line revenue, city-level sales, and customer payment preferences.

### Dataset
- Total records: 1,000 transactions
- Period: January to March 2019
- Missing values: 0
- Duplicate rows: 0

### Technologies Used
- Python
- Pandas
- Matplotlib
- Seaborn
- Google Colab

### Project Workflow
1. Loaded the supermarket sales dataset.
2. Cleaned column names and converted dates.
3. Checked for missing values and duplicate records.
4. Calculated descriptive statistics.
5. Visualized sales by product line and city.
6. Analyzed transaction counts by payment method.

**Conclusion:** This project demonstrates the use of exploratory data analysis and visualization to understand supermarket sales data.
